Disk Drive

The console reads games from a proprietary 3" mini-DVD (Nintendo's "GameCube Game Disc"). The drive is an intelligent, command-driven device built around a small CPU with firmware, developed with Matsushita, and controlled by the Flipper Disk Interface (DI).

1. Media characteristics

ParameterValue
Format3" mini-DVD, Matsushita technology
Capacity1,459,978,240 bytes (~1.5 GB)
RotationConstant Angular Velocity (CAV)
Densityconstant; sectors spiral edge→centre
Read rate≈ 2–3 MB/s (~13× CD-ROM)
Audiostreamed DVD-Audio, ADPCM, 48 kHz

A proprietary copy-protection scheme (unlike CSS on standard DVDs) combines non-standard barcodes with encryption of the sector data, decrypted on the fly by the DVD controller. A GameCube disc cannot be read on ordinary PC optical drives.

2. Drive architecture

The drive is an intelligent device: it contains a microcontroller from the MN-10200 family running proprietary firmware from an internal ROM. The console therefore talks to it at the command level, and the drive performs its own copy-protection de/encryption internally. Two interaction modes are exposed:

  1. Immediate commands — quick control (motor, DVD-audio stream, register access).
  2. DI DMA — bulk data transfer between disc and main memory (the normal path); all transfers are 32-byte aligned.

3. Disk Interface (DI)

The DI register block is at physical 0x0C006000 (32-bit registers).

RegisterOffsetPurpose
DISR0x00Status: break & transfer-complete interrupts/masks, device error, break request
DICVR0x04Cover/loose-lid status and interrupt
DICMDBUF0..20x08–0x1012-byte command packet
DIMAR0x14DMA memory address (32-byte aligned)
DILENGTH0x18DMA transfer length (bytes, 32-byte aligned)
DICR0x1CControl: read/write, DMA/immediate, transfer start
DIIMMBUF0x20Immediate-mode register data
DICFG0x24Drive configuration latched at reset

5. DVD-Audio streaming (AIS)

SignalDirDescription
AISDISerial left/right audio bitstream from the drive
AISLROFrame/left-right signal at 32/48 kHz; also gates data flow
AISCLKOFree-running bit clock for AISD

The stream is sample-rate-converted to 48 kHz by the Audio Interface before mixing.

Peripheral Devices (EXI, SI)

This section covers the two on-chip peripheral interfaces in the Flipper IO block: the Expansion Interface (EXI) and the Serial Interface (SI). The controller (SI) and memory-card/extended (EXI) hardware lives inside Flipper.

1. Expansion Interface (EXI)

EXI is the general-purpose peripheral bus, wired to the console's external connectors and a few on-chip peripherals.

1.1 Channels and devices

There are three independent EXI channels, each with a selectable clock rate (16 / 8 / 4 / 2 / 1 MHz) and its own chip selects:

ChannelTypical device
EXI0CS0_0 = internal boot ROM / RTC; CS0_1 = internal flash ROM; CS0_2 = external device (modem, broadband adapter)
EXI1CS1_0 = external device (modem, etc. — serial port 1)
EXI2CS2_0 = external debugger (serial port 2)

EXI0 is the 16-bit / highest-bandwidth channel and is used by the Broadband Adapter and the modem. It also contains the descrambler for the boot ROM and drives an internal 32 MHz line that is electromagnetically isolated from the slower external line.

1.2 Transfer modes

  • Immediate — small (1–4 byte) transfers between a CPU register and the device, full-duplex (send and receive simultaneously). Used for command/status register traffic.
  • DMA — bulk data between main memory and the device, staged through a 32-byte internal buffer. Used for large blocks and memory cards.

1.3 Interrupts and presence

Each channel can raise a transfer-complete interrupt and, for external-device channels, an EXT_INT on EXT_IN edge to detect insertion/removal. A device must be selected (chip select + clock frequency) before a transfer; the OS driver performs a probe/lock/unlock handshake.

1.4 Register map

EXI registers live at physical 0x0C006800, one 20-byte (5-word) block per channel:

WordRegisterPurpose
+0x00EXInSTATStatus/control: clock, device select, interrupt flags
+0x04EXInDATAImmediate-mode data/command
+0x08EXInCTRLTransfer control (length, immediate/DMA, start)
+0x0CEXInMARDMA memory address (32-byte aligned)
+0x10EXInLENDMA length

2. Serial Interface (SI)

SI handles the four controller ports and the keyboard. It is at physical 0x0C006400 (32-bit registers).

2.1 Channels and buffers

There are four SI channels. Each has:

  • An output buffer — one command byte + two output data bytes (CMD, OUTPUT0, OUTPUT1), double buffered.
  • An input buffer (high + low) — up to 8 response bytes plus per-transfer error/status bits, double buffered with a locking read sequence.

2.2 Polling and communication

  • Polling — the hardware periodically polls enabled channels every X horizontal video lines, Y times per frame, from vertical blank (SIPOLL). VBCPYn defers output buffer writes to the next blank (for 3D shutter glasses).
  • Communication (SICOM) — a general-purpose multi-byte transfer to a single channel's registers, with programmable lengths (0 = 128 bytes) and start/complete reporting.

2.3 Errors and clock lock

SISR reports per channel: no-response (device absent), collision, overrun and underrun, plus write/read status. SIEXILK prevents the software from setting the EXI clock to 32 MHz (SI shares the EXI clock tree).

3. Controller (the SI device)

The GameCube controller is an intelligent device that responds to short command/response packets. Communication is serial, half-duplex, over a single data line using pulse-width (duty-cycle) modulation, big-endian. It has:

  • Two analog sticks (left main + right "C" stick).
  • Two analog triggers (L, R) with a digital "click" at full press.
  • Digital buttons A, B, X, Y, Z and Start, plus a D-pad.
  • A rumble motor (host-controlled).
  • Auto-calibration of the analog peripherals.

4. Devices on the peripheral bus

  • Memory cards (two slots) — EXI devices; 512 KB / 2 MB / 8 MB at retail.
  • Broadband Adapter (BBA) — 10BASE-T Ethernet, on the parallel/EXI0 port.
  • Modem — serial port / EXI1.
  • Boot ROM, flash ROM, RTC and settings SRAM — on-chip EXI0 devices.
  • Keyboard — via SI.
  • Game Boy Advance — through the controller/SI port as a second screen/controller.
  • Game Boy Player — the add-on that emulates Game Boy consoles (uses EXI).

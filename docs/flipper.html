Flipper Chipset

Flipper is the single ASIC that is the console's northbridge, graphics processor, audio DSP and I/O controller. Designed by ArtX (led by Wei Yen, largely ex-SGI); ArtX was acquired by ATI late in the design, but the Flipper was already complete.

1. Role and connection

Physically Flipper sits between the Gekko CPU, the main 1T-SRAM, the ARAM SDRAM, the disc drive, the audio DAC, the video encoder and every peripheral connector. It is reached by the CPU only over the Gekko–Flipper bus (32-bit address / 64-bit data, 162 MHz) and hosts all memory-mapped hardware registers.

2. Memory interface (MI) and protection

The MI is the arbitration hub. Its bus users (masters) are: PI (Gekko), CP (GFX command processor), TC (texture cache), PE (pixel engine), IO (peripheral DMA), DSP and VI (video), plus write-buffer and SDRAM/ARAM controller paths.

MI provides protection for up to 4 regions of main memory (1024-byte pages, access modes deny/read-only/write-only/full), each raising a dedicated interrupt on violation. Because the bus only carries 64-bit transactions, an uncached byte/halfword store writes a full 8-byte block (a quirk that software can exploit for fast memory clearing).

3. Graphics processor (GFX)

The GFX is a fixed-function pipeline (no programmable shading) with three stages: command processor, geometry/lighting, and rasterizer.

  • Command processor: on-chip FIFO (32-byte chunks), a call FIFO for display lists (no nesting), a vertex cache; vertex attributes from stream or arrays in main memory (incl. fixed-point).
  • Geometry: fixed-point math; 8 hardware RGBA lights (diffuse/specular), angle & distance attenuation, toon shading, bump mapping, 64-entry matrix RAM (plus dual-texture transform).
  • Rasterizer:
    • 24-bit RGB color, 24-bit Z.
    • Embedded framebuffer (EFB): 2 MB 1T-SRAM, native ≈ 640×528; drawing happens here, then copied (optionally scaled/filtered) to an external framebuffer (XFB) in RAM for TV output.
    • Texture memory (TMEM): 2 MB with a cache; textures up to 1024×1024; formats include indexed TLUT, RGB565, RGB5A3, RGBA, IA4/8 and S3TC; alpha, 3D and indirect texturing.
    • Multitexturing up to 16 texture sets; mip-mapping, bilinear/trilinear, anisotropic up to 4×.
    • Fog, blending, gamma correction.
    • Stated performance ≈ 6–12 M polygons/s (~100–200 k triangles/frame).

3.1 GFX→Gekko FIFOs

  • PI FIFO — Gekko side; CPU writes burst stores to 0x0C008000, write pointer advances by 32 bytes with wrap-around control (CPBAS/CPTOP/CPWRT/CPABT).
  • CP FIFO — GFX side; command processor reads the stream from main memory (base/top/watermarks/pointers).

4. Audio DSP and Audio Interface

4.1 DSP

A 16-bit Macronix DSP at 81 MHz (1/6 CPU clock).

  • 8 KB instruction RAM (IRAM) + 8 KB instruction ROM (IROM) — IMEM.
  • 8 KB data RAM (DRAM) + 4 KB data ROM (DROM, coefficients) — DMEM.
  • Custom ADPCM decoder, ARAM accelerator, DMA to main memory, mailbox registers for CPU communication.
  • Mixes 64+ 3D-positioned channels with reverb, echo and per-channel ADSR, in parallel with CPU and GFX.

4.2 Audio Interface

  • AI DMA streams PCM from main memory in 32-byte blocks into a 32-byte FIFO drained at 32/48 kHz stereo; SRC keeps the stream at 48 kHz.
  • Auxiliary/streaming (AIS) receives DVD audio bitstream and converts to 48 kHz.
  • Output pins aid/ailr/aiclk drive the stereo DAC.

5. Video Interface (VI)

VI reads the XFB from main memory, performs horizontal scaling and optional filtering/antialiasing, and drives the TV encoder. It generates the vertical-blank interrupt (programmable to any beam position), supports light-gun latching (guntrg), interlaced, double-strike and progressive (480p) modes, PAL/NTSC/M-PAL/PAL60 output, and stores the video buffer in Y1UY2V-packed format.

6. Boot ROM / reset

Flipper generates the Gekko reset vector (0xFFF00100) and reset signal. The IPL reads the 2 MB encrypted boot ROM (exposed on EXI0 and descrambled by Flipper), which holds the initialisation code, the system menu and language fonts.

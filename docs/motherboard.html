Motherboard, Connectors & Components

Scope: the retail HW2 production board (codename Dolphin). Earlier developer boards are not covered.

1. Board layout

The console is built around two large ICs on the main CPU board (stamped DOL-CPUP-01), plus a few memory/auxiliary chips. All system logic except the TV-out encoder path sits inside one ASIC, Flipper.

Total system memory is therefore 24 MB of fast 1T-SRAM plus 16 MB of slower ARAM — 40 MB in all.

2. System buses

  • 32-bit address bus, 64-bit data bus.
  • Bus clock 162 MHz (one third of the 486 MHz CPU).
  • Sustained bandwidth ≈ 1.3 GB/s.
  • Transaction sizes: 1, 2, 4, 8 and 32 bytes (32-byte burst for cache fills and write-gather).
  • ARAM: separate 8-bit cable at 81 MHz, ≈ 80 MB/s, reached only via DMA.

4.2 Controller ports (SI)

Four identical ports, one per SI channel. Serial, half-duplex, over a single data line using pulse-width (duty-cycle) modulation, transferred big-endian. The controller is an intelligent device.

4.3 Peripheral ports (EXI)

  • Parallel / high-speed — EXI0, the 16-bit highest-bandwidth channel; three chip selects reach the internal boot ROM/RTC, internal flash ROM, and an external device (modem, broadband adapter). Contains the boot-ROM descrambler.
  • Serial port 1 — EXI1 (e.g. a modem).
  • Serial port 2 — EXI2 (external debug hardware).
  • Two memory card slots — wired to the EXI bus; 512 KB / 2 MB / 8 MB at retail.

5. Power and physical

  • Power adapter: DC 12 V × 3.5 A.
  • Dimensions: ≈ 4.3″ (h) × 5.9″ (w) × 6.3″ (d).

IBM Gekko Processor

The Gekko is the console's CPU: a PowerPC 750-derived 32-bit processor with custom IBM extensions for the GameCube.

1. General characteristics

ParameterValue
Vendor / designIBM, based on the PowerPC 750CXe
Process0.18 µm CMOS with copper interconnects
Die size≈ 40 mm²
Transistors≈ 21 million
Power≈ 5 W
Core clock486 MHz (3 × the 162 MHz bus)
Performance≈ 1125 MIPS; scalar FPU ≈ 1.9 GFLOPS, peak ≈ 10.5 GFLOPS (Paired-Single)

2. Register model

  • 32 × 32-bit general-purpose registers (r0–r31; r1 is the stack pointer).
  • 32 × 64-bit floating-point registers (f0–f31).
  • Condition register (CR), MSR, FPSCR and ≈ 60 SPRs.
  • Full PowerPC integer, floating-point, load/store, branch and system instruction set.

3.1 Locked cache (LC) mode

The data cache can split so that 16 KB stays a normal 4-way cache and the other 16 KB becomes a software-managed locked cache (scratchpad):

  • Enabled by HID2[LCE].
  • Lines allocated with dcbz_l (typically at 0xE0000000, mapped by a DBAT).
  • dcbi / dcbf deallocate; pseudo-LRU reallocates when the set is exhausted.
  • Switching between normal and locked mode is slow (~50 µs).

3.2 Write-gather buffer (WBUF)

A small buffer (~4 × 32-byte lines) that collects single-beat stores to one physical address and emits a 32-byte burst once full.

  • Enabled by HID2[WPE]; address set in WPAR (SPR 921).
  • Targeted at 0x0C008000, the burst feeds the GFX command FIFO.

4. Paired Single (SIMD)

Gekko's distinctive extension: a 64-bit FP register is treated as two 32-bit singles, so two single-precision operations run in parallel. Dedicated paired-single instructions roughly double scalar FPU throughput — the source of the ~10.5 GFLOPS peak.

5. Memory management unit (MMU)

  • Separate data (DMMU) and instruction (IMMU) units.
  • Block address translation via DBAT/IBAT — used exclusively by Dolphin OS.
  • Segment registers + page-table translation (GC-Linux, direct-ARAM tricks).
  • TLB: 128-entry, two-way set-associative per MMU.
  • Unmapped access → MMU exception; protected main-memory region → Flipper MI interrupt.

6. Clocks

The core clock comes from an on-die PLL, whose multiplier is selected by the PLL_EXT/PLL_CFG[0:3] strap pins (2×–16× plus bypass modes).

Nintendo GameCube Hardware

An architectural overview of the retail HW2 (Dolphin) board — the Gekko CPU, the Flipper chipset, the memory subsystem, the disc drive and the peripheral interfaces — gathered from the hardware documentation, chip RTL and reverse-engineering sources in this repository.

Specified at the signal level · light & dark themes

Motherboard & Connectors

Board layout, the 162 MHz system bus, Flipper device pins, and the disc-drive / peripheral connector signal maps.

Clock Generator

The 27 MHz reference, the clock-generator chip, the system clock tree and PLL straps, and how emulators derive their timing domains.

IBM Gekko CPU

486 MHz PowerPC 750 derivative: caches, locked cache, write-gather buffer, Paired-Single SIMD, MMU and clocking.

Flipper Chipset

The single ASIC that is northbridge, GPU, audio DSP and I/O controller — memory arbitration, the fixed-function graphics pipeline, DSP and video.

Video Interface

The scan-out engine that reads the external framebuffer, generates NTSC/PAL timing, and scales horizontally — the register map and emulator model.

Memory Interface

The Flipper arbitration hub: memory masters, queues, arbiter priority, write buffering and coherency, MARR protection, and the 1T-SRAM "Splash" link.

Processor Interface

The Flipper block on the Gekko 60x bus: 16-bit register access, transfer types and prefetch, the interrupt controller, PI errors, the memory map and reset.

Disc Drive

The intelligent Matsushita 3" mini-DVD drive: media, copy protection, DI interface, signals and streamed DVD audio.

Peripherals (EXI & SI)

The Expansion Interface and Serial Interface: channels, transfers, controllers, memory cards, broadband & modem, and the controller protocol.
